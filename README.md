# Hoopland Theme Assets

Public raster assets served at `https://hoopland-themes.rosen.systems/logos/<filename>`.

## Content boundary

- This repository contains public image assets only.
- Publish only lowercase `.png`, `.jpg`, `.jpeg`, or `.webp` files below `logos/`.
- Do not add HTML, JavaScript, SVG, configuration, credentials, or deployment files.
- The public Worker and Cloudflare deployment credentials remain outside this repository.

## Publishing

After an authorized contributor pushes a logo to `logos/`, it is available through the public domain at the same path. Example:

`logos/boston-banshees.png` → `https://hoopland-themes.rosen.systems/logos/boston-banshees.png`
